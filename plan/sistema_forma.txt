# Sistema de Forma

A Forma representa o momento atual de desempenho do jogador. Ela é um valor dinâmico, calculado a partir das atuações recentes do atleta.

O sistema utiliza uma escala interna de **0 a 100**. Esse valor é convertido em uma classificação qualitativa para ser exibida ao jogador.

A Forma é calculada considerando as **últimas 5 partidas oficiais em que o jogador participou**. Apenas partidas nas quais o atleta entrou em campo são consideradas.

Para cada uma das cinco partidas, o jogador recebe uma **nota de desempenho de 0 a 10**. Essas notas são utilizadas para calcular a média de desempenho recente.

A média é calculada da seguinte forma:

**Média de Forma = (Nota 1 + Nota 2 + Nota 3 + Nota 4 + Nota 5) ÷ 5**

Essa média de 0 a 10 é então convertida para uma escala de 0 a 100:

**Forma = Média de Desempenho × 10**

Por exemplo, se as últimas cinco partidas tiveram as notas:

**7,2 — 7,8 — 6,9 — 8,1 — 7,5**

A média será:

**(7,2 + 7,8 + 6,9 + 8,1 + 7,5) ÷ 5 = 7,5**

Convertendo para a escala interna:

**7,5 × 10 = 75**

Portanto, o jogador possui **Forma 75**.

A classificação qualitativa é determinada pelo valor final:

**0–19: Em crise**

**20–39: Abaixo da média**

**40–59: Irregular**

**60–74: Em boa fase**

**75–89: Em grande fase**

**90–100: Inspirado**

Assim, a Forma é essencialmente uma representação quantitativa da **média de desempenho das últimas cinco partidas**, convertida posteriormente para uma escala de 0 a 100 e apresentada ao jogador através de uma classificação qualitativa.
